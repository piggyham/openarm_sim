三、技术领域

本发明涉及机器人仿真、数字孪生、机器人学习、运动控制和多模态数据处理技术领域，尤其涉及一种面向双臂机器人，将仿真轨迹转换为与实机采集格式和物理语义一致的数据、将实机的实测状态和指令状态映射回仿真模型，并通过因果时间同步、双轨迹显示及动力学/运动学双模式回放实现仿真—实机差异定位的方法、系统、设备及存储介质。


四、背景技术

机器人策略通常先在仿真环境中采集或生成轨迹，再使用所述轨迹训练控制策略，最后部署到真实机器人。现有方案中，仿真数据和实机数据往往分别使用不同的数据目录、字段名称、采样频率、时间戳基准、夹爪编码方式和相机命名方式。即使机械臂的关节数量相同，仿真端与实机端仍可能出现以下问题：

1. 仿真数据使用仿真秒，实机数据使用 Unix 纳秒，导致关节、控制指令和相机帧难以严格对齐；
2. 实测关节位置、控制器目标位置和视觉图像采用不同采样频率，若简单使用最近邻或统一线性插值，可能把未来控制指令泄漏到当前时刻，破坏控制因果性；
3. 仿真夹爪以物理开度表示，而部分实机数据以零值闭合、负值张开或其他归一化编码表示，容易产生方向相反或比例错误；
4. 仿真相机与实机相机命名、安装位置及图像时间戳不同，难以进行同帧对比；
5. 仅把实机实测关节角写入三维模型，无法同时观察“机器人被要求到达的位置”和“机器人实际到达的位置”；
6. 若把目标机器人模型直接加入同一动力学世界，目标模型可能参与碰撞、接触或动力学计算，反而改变实测模型的物理状态；
7. 仅使用运动学回放可以精确显示录制姿态，但无法暴露控制器跟踪误差；仅使用动力学回放则难以区分录制误差、控制器误差和仿真模型误差；
8. 仿真数据即使数值内容正确，若输出文件结构和字段 schema 与实机工具链不一致，仍需维护两套转换、校验和训练流程，增加了 sim-to-real 部署成本。

因此，需要一种能够在数据结构、时间语义、关节语义、夹爪语义、相机语义和动力学验证层面建立双向一致关系的技术方案，使仿真数据可直接进入实机数据工具链，同时使实机轨迹能够被数字孪生系统准确重放、比较和诊断。


五、术语和约定

1. Actual：由编码器、关节状态接口或实机观测文件获得的机器人实测状态。
2. Target：控制器向机器人发送的关节目标或其他指令状态，又称 commanded target。
3. 双轨迹：同一时间基准下的 Actual 序列与 Target 序列。
4. 公共状态向量：按预定顺序排列的多机械臂关节和夹爪状态。本实施例为十六维：左臂七关节、左夹爪、右臂七关节、右夹爪。
5. 物理开度：用长度单位表示的夹爪开口量，例如零表示闭合、0.044 米表示完全张开。
6. Reality-to-Sim：将实机状态、实机指令和实机视觉数据映射到仿真/数字孪生系统。
7. Sim-to-Real 数据同构：仿真数据按照与实机数据相同或兼容的目录、字段类型、单位、时间戳和相机命名进行输出。
8. 运动学回放：直接写入机器人广义坐标并执行正运动学，不通过动力学积分。
9. 动力学回放：把目标状态交给控制器，经力矩计算和物理积分得到仿真实际状态。


六、发明目的

本发明旨在提供一种仿真—实机双向关系构建方案，以至少解决下列技术问题之一：

1. 使仿真轨迹无需针对实机工具链进行二次人工适配即可被读取、校验或用于训练；
2. 在不破坏控制因果性的情况下，对异步的实测状态、控制目标和多相机图像进行统一时间同步；
3. 在同一数字孪生场景中，同时呈现实机 Actual 和 Target，且保证 Target 表示不参与实际物理计算；
4. 通过运动学模式与动力学模式的切换，区分姿态映射误差、控制跟踪误差和动力学建模误差；
5. 建立从仿真数据生成、策略训练、实机部署、实机回放、差异分析到仿真参数修正的数据闭环。


七、技术方案概述

本发明提供一种面向机器人的仿真—实机双向映射和验证方法，包括：

S1、定义仿真端和实机端共享的机器人状态语义，包括机械臂顺序、关节顺序、关节单位、夹爪物理开度、相机语义及任务信息；

S2、获取来自仿真端或实机端的多源时序数据，所述多源时序数据至少包括实测状态序列，可选地包括控制目标序列和多个视觉序列；

S3、确定各时序数据共有的有效时间区间，并在该有效时间区间内生成统一采样时间网格；

S4、针对不同数据语义采用不同的重采样规则：对连续变化的 Actual 使用线性插值，对具有保持语义的 Target 使用零阶保持，对相机图像使用时间最近邻匹配，以防止未来目标指令泄漏到当前采样时刻；

S5、把不同来源的关节和夹爪数据映射为公共状态向量，其中关节按照统一顺序和单位排列，夹爪数据由源编码转换为物理开度；

S6、对于 Sim-to-Real 方向，把仿真时间转换为实机工具链使用的绝对时间戳，将仿真观测、控制目标和多个相机图像写入与实机数据相同或兼容的目录结构和字段 schema；

S7、对于 Reality-to-Sim 方向，以 Actual 作为数字孪生中实体机器人模型的权威状态，同时使用与所述实体机器人模型共享模型定义但具有独立状态数据的目标模型表示 Target；

S8、对目标模型执行正运动学，把目标模型的可视几何以半透明方式追加到实体机器人模型的渲染场景中，并禁止目标模型参与实体机器人模型的碰撞、接触和动力学积分；

S9、提供运动学回放模式和动力学回放模式：运动学回放模式直接复现实测状态，动力学回放模式以控制目标驱动控制器和物理引擎生成仿真实际状态；

S10、基于 Actual、Target、动力学回放结果和同时间视觉数据中的至少两种，输出关节误差、夹爪误差、轨迹趋势、图像对比或异常标识，用于数据质量判定、控制器调节、仿真参数调节或机器人策略评估。


八、双向闭环关系

本发明中的仿真与实机不是单向替代关系，而是如下双向闭环：

仿真任务/脚本专家
        ↓
生成状态、目标、力矩、速度和多相机数据
        ↓
转换成与实机相同的 v0.3.0 数据结构和时间语义
        ↓
统一工具链校验/训练机器人策略
        ↓
部署至实机并采集 Actual、Target 和相机流
        ↓
按因果规则重采样并映射回数字孪生
        ↓
Actual 实体 + Target 非物理虚影 + 动力学重放
        ↓
分析跟踪误差、建模误差及视觉域差异
        ↓
调整仿真参数、控制参数、数据筛选条件或训练配置
        └──────────────────────→进入下一轮仿真和训练


九、有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 仿真数据和实机数据使用统一数据结构和物理语义，减少数据转换链路及训练端分支代码；
2. Actual、Target 和相机采用语义相关的重采样方式，既实现跨频率同步，又保持控制指令的因果性；
3. 使用物理开度统一多种夹爪编码，避免开合方向、比例或单位不一致；
4. Actual 和 Target 可在同一三维场景中直观比较，而目标虚影不参与物理计算，不会污染实测状态或仿真接触结果；
5. 运动学回放精确复现实机姿态，动力学回放暴露控制器和物理模型的跟踪差异，两者组合可提高误差定位能力；
6. 实机数据可离线回放，也可通过实时状态流形成在线数字孪生；
7. 多相机录制画面和仿真相机画面按照同一时间网格并排显示，可用于发现相机外参、场景几何和视觉域偏差；
8. 对关节目标进行模型限位裁剪，并保留原始 Actual 用于误差展示，兼顾仿真安全和数据真实性；
9. 仿真数据可直接经过实机厂商工具链的结构校验，从数据层提前发现 sim-to-real 接口问题。

十一、具体实施方式

以下结合双臂 OpenArm 机器人及瓶状物接力任务说明本发明。所属领域技术人员应理解，机械臂数量、关节数量、任务对象、仿真引擎、数据文件类型和相机数量均可替换，本实施例不构成限制。

实施例一：公共状态语义

为仿真和实机定义十六维公共状态向量：

[左臂关节1～7，左夹爪物理开度，右臂关节1～7，右夹爪物理开度]。

七个旋转关节均以弧度表示。夹爪采用物理开度表示，零表示闭合，预定最大值表示完全张开。若实机数据已经声明 opening_m 编码，则直接使用并裁剪到合法范围；若历史数据使用零值闭合、负值逐渐张开的归一化编码，则通过如下方式转换：

opening = FULL_OPENING × clip(-raw, 0, 1)。

在另一兼容实施例中，若源格式采用 raw = opening/FULL_OPENING - 1，则按照该编码元数据执行逆变换。通过在数据集元数据中记录 gripper_encoding，可支持不同代际的数据而不改变上层回放接口。

实机相机和仿真相机按照语义进行映射：

head → front；
wrist_left → left_wrist；
wrist_right → right_wrist。

映射后的状态、目标、时间戳、相机和来源标识被封装为统一 EpisodeData。上层回放系统无需知道输入来自 LeRobot、仿真转换集、实机遥操作集还是实时数据源。


实施例二：因果一致的多源同步

实机左右臂状态、左右臂控制目标和三个相机流可能具有不同起止时间及采样频率。本实施例先求取所有必需状态流的公共时间区间：

T_start = max(各流首时间)；
T_end   = min(各流末时间)。

若存在控制目标流，则进一步把目标流的有效范围加入公共区间约束。在 [T_start, T_end) 内按照预定输出频率生成均匀时间网格。

对于 Actual 关节状态，因其表示连续机械运动，按各关节分别执行线性插值；对于 Target，由于控制目标在新命令到来前持续有效，采用零阶保持，即选取不晚于当前网格时刻的最近一条目标命令；对于相机帧，选择时间戳与网格时刻最接近的图像。

相较于对 Target 使用线性插值或普通最近邻，本实施例的零阶保持不会在当前时刻使用未来才到达的控制命令，从而保持控制因果性。对于在线数据源，可在接收到最新 Actual 和 Target 后直接更新单帧 EpisodeData，并强制采用运动学 Reality 模式，避免对实时实测状态进行二次动力学推演。


实施例三：Sim-to-Real 同构数据生成

仿真系统以固定控制频率采集：

1. 双臂关节位置和夹爪开度；
2. 双臂关节速度；
3. 双臂关节力矩或执行器作用量；
4. 双臂关节目标；
5. 前视、左腕和右腕图像；
6. 仿真时间和采集开始时的墙钟时间；
7. 任务描述、成功标记和 episode 标识。

仿真时间通过下式转换为绝对纳秒时间戳：

unix_ns(i) = wall_start_ns + round((sim_time(i)-sim_time(0))×10^9)。

转换后的单个 episode 使用如下示例结构：

metadata.yaml
episodes/<id>/
    obs/arms/left/state.parquet
    obs/arms/right/state.parquet
    action/arms/left/qpos.parquet
    action/arms/right/qpos.parquet
    cameras/head/<timestamp_ns>.jpeg
    cameras/wrist_left/<timestamp_ns>.jpeg
    cameras/wrist_right/<timestamp_ns>.jpeg

观测状态文件记录 qpos、qvel 和 qtorque；动作文件记录控制目标；相机文件名直接使用同一绝对纳秒网格。仿真夹爪物理开度按照目标实机格式进行编码，相机名称转换为实机名称。由此生成的数据可直接使用实机数据集读取器和验证器进行 schema 校验。

在本实施例的验证数据中，仿真数据以 20Hz 采集，关节、目标和三相机共享严格单调的 50ms 时间间隔。这里的具体频率仅为示例，实际系统可根据机器人控制周期设置。


实施例四：Reality-to-Sim 双轨数字孪生

读取实机 episode 时，把观测文件中的 qpos 映射为 Actual，把动作文件中的 value 映射为 Target。Actual 与 Target 均转换为公共十六维状态，但保持两个独立序列。

数字孪生系统建立第一 MjData 作为权威 Actual 数据对象，并建立第二 MjData 作为 Target 数据对象。两个数据对象共享同一机器人模型定义，以确保几何尺寸、关节轴、零位和运动学链一致，但第二数据对象不被送入物理积分。

在运动学 Reality 模式下：

1. 将当前 Actual 直接写入第一数据对象的机器人广义坐标；
2. 对第一数据对象执行正运动学，得到实机实测姿态对应的三维实体；
3. 在不修改第一数据对象的前提下，把第一数据对象中的非机器人状态复制到第二数据对象；
4. 仅把第二数据对象中的机器人关节和夹爪坐标替换为 Target；
5. 对第二数据对象执行正运动学；
6. 将第二数据对象的机器人可视几何追加到已由第一数据对象建立的渲染场景中；
7. 把所追加几何设置为半透明或特定颜色，形成 Target 虚影。

Target 虚影仅由渲染场景中的几何副本构成，不参与第一数据对象的碰撞、接触、约束求解或动力学积分。因此，Target 的显示不会影响 Actual 实体的位置和数字孪生场景的物理状态。

如果 Target 缺失、非法或超出预定显示条件，则隐藏虚影但继续显示 Actual；如果 Actual 超出仿真模型关节限位，则用于渲染的姿态被裁剪到合法范围，同时界面仍显示未裁剪的原始 Actual 数值和超限标识，避免隐藏真实数据问题。


实施例五：动力学/运动学双模式误差分离

系统提供两种回放模式。

1. 运动学模式：将 Actual 逐帧写入仿真广义坐标并执行正运动学。该模式下三维实体严格表示实机测量姿态，适合检查关节顺序、零位、夹爪映射、时间同步和相机对齐。

2. 动力学模式：当存在 Target 时，以 Target 作为控制器目标；当不存在 Target 时，以记录状态作为目标。控制器生成力矩，仿真引擎在一个输出帧周期内执行多个物理子步，得到仿真实际状态。该模式适合观察仿真控制器和动力学模型对同一目标命令的响应。

通过组合比较可分离误差来源：

（a）若运动学模式中的模型姿态即与实机图像不一致，则优先检查关节顺序、零位、模型尺寸、相机外参或夹爪编码；
（b）若运动学模式一致而 Target 与 Actual 偏差较大，则说明实机控制跟踪存在延迟、饱和、摩擦或负载影响；
（c）若实机 Actual 与 Target 的偏差和动力学回放 Actual 与 Target 的偏差明显不同，则说明仿真控制器参数或动力学参数与实机不一致；
（d）若关节姿态一致但仿真图像和实机图像差异较大，则优先调整场景几何、材质、光照或相机参数。

在本实施例中，手臂关节在动力学模式下由 PD/阻抗控制器跟踪，控制器具备力矩限幅、速度保护和关节软限位。夹爪可根据具体模型选择动力学跟踪或直接运动学写入；当夹爪伺服和指垫接触导致非目标自锁时，可直接写入合法夹爪开度，而保持手臂关节继续进行动力学跟踪。


实施例六：多模态同帧对比及诊断

每个统一时间帧同时输出：

1. Target 十六维状态；
2. Actual 十六维状态；
3. Target-Actual 误差；
4. 仿真 front、left_wrist、right_wrist 图像；
5. 实机录制的 head、wrist_left、wrist_right 同步图像；
6. 可交互自由视角图像；
7. 关节趋势曲线、误差超限标识和数据来源标识。

系统可针对各关节或夹爪设置误差阈值。误差超过阈值时，对相应通道、帧或 episode 生成异常标识。异常结果可用于剔除低质量训练数据、重新标定相机、修改控制器参数、调整仿真摩擦/阻尼/质量参数，或者形成后续策略训练的样本权重。


实施例七：策略训练与评测闭环

仿真同构数据和实机数据可进一步转换为同一机器人学习数据格式。转换时保持统一的相机键、机器人状态顺序、动作顺序和语言任务描述。策略训练后，在仿真环境中根据实时渲染图像和机器人状态预测动作块，控制双臂完成任务；随后将同一策略部署到实机。

实机执行产生的新 Actual、Target 和相机流再次进入 Reality-to-Sim 模块。系统根据实机与仿真的跟踪差异、视觉差异和任务成功情况更新以下至少一项：

1. 仿真机器人质量、惯量、摩擦、阻尼或执行器参数；
2. 控制器增益、限幅、动作缩放或控制周期；
3. 相机内参、外参、分辨率或裁剪方式；
4. 训练数据筛选、归一化统计或仿真随机化范围；
5. 策略训练超参数或评测条件。

从而形成可迭代的 sim-to-real/reality-to-sim 闭环。


实施例八：线程和通信实现

在采用线程局部图形上下文的实现中，仿真模型、仿真数据、控制器和离屏渲染器均在同一专用仿真线程中创建和使用。网络事件循环通过线程安全命令队列向仿真线程发送播放、暂停、跳转、模式切换和相机控制命令；仿真线程通过最新帧槽向网络事件循环发布结果。

所述最新帧槽只保留最新可用帧，使慢速浏览器客户端丢弃历史帧而不阻塞仿真和实时镜像。该结构可同时支持离线 episode、实时实机状态流和多个浏览器客户端。

十三、摘要

本发明公开了一种面向机器人的仿真—实机双向映射、因果同步与数字孪生验证方法、系统、设备及存储介质。该方法获取机器人实测状态、控制目标和多相机视觉等异步时序数据，在公共有效时间区间生成统一采样网格，并针对数据语义分别采用线性插值、零阶保持和时间最近邻匹配；随后将关节、夹爪和相机映射为统一物理语义。实测状态驱动数字孪生中的实体机器人，控制目标驱动共享模型定义但具有独立状态数据的目标机器人，对目标机器人执行正运动学后，仅将其可视几何以半透明形式追加到实体机器人渲染场景，使其不参与碰撞、接触或动力学积分。系统还提供运动学回放和动力学回放，用于分离姿态映射误差、控制跟踪误差和动力学建模误差。仿真数据可被转换为与实机数据相同或兼容的目录、字段、单位和绝对时间戳结构，从而形成仿真生成、策略训练、实机执行、实机回放和参数修正的双向闭环。
